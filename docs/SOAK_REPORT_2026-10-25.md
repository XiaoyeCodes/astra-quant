## 已修复与仍存在的问题

1. **断线混入演示数据**：WebSocket 断开或桥接重启后，旧页面会把真实模拟账户替换成 DEMO。现保留最近账户快照、标记过期并提示重连，恢复后更新。真实浏览器主动关闭 WebSocket 的复测通过。
2. **止损接口输入异常**：空值、对象导致 500，缺少比例会被当作 0，可能关闭保护。现统一返回 400、保留原值，明确传入数字 0 才能关闭。控制接口的非对象请求也会拒绝。
3. **DeepSeek 结构化输出不兼容**：原生智能体发送 `json_schema` 导致 400。仅对官方 DeepSeek 主机改用 `json_object`，把原 schema 放入提示并保留智能体解析校验，同时关闭思考输出。其他主机保持原参数。实测和单元测试通过。依据：[DeepSeek JSON Output 官方说明](https://api-docs.deepseek.com/guides/json_mode/)。
4. **指数不调仓**：原预设没有提供有效策略周期依赖。补齐 SimpleStrategyEvaluator、RSI 和 1h 周期后，真实行情下触发 50/30/20 配置的三币买入；日刷新周期及权重保持原值。
5. **导入预设触发重复插件安装**：最小预设缺少安装版本和基础插件配置。13 个预设现包含固定的 OctoBot 2.1.1 元信息及参考配置中的连接器、WebInterface、自动化等基础组件，保留各自唯一的交易模式和指标选择。启动适配也会从已安装参考配置补齐缺失部分。仅添加版本号会漏启 WebInterface，最终重启验证发现并纠正了这一点。未安装插件时仍走正常安装流程。
6. **跨策略止损漏卖旧持币**：首轮演练确认，BTC 网格下的原生 `sell_all` 仅卖出 BTC，遗漏之前指数买入的 ETH、SOL。新增仅限模拟现货的清算适配，按实际持币查询市场、取得真实价格后卖出；不扩大策略交易对，也不作用于真实交易账户。复测及恢复结果见下一节。
7. **AI 仓位外部数据阻断**：新闻和市值数据源返回 401，当前不能视为可用，已在 UI 和接口层拒绝选择。单次复测技术分析阶段即记录了 27344 tokens 消耗，仍未产生完整分配，不适合当前配置直接运行。
8. **手续费口径差异、旧页面重连异常堆栈未保留**：仍需后续定位；不能据此声明全部缺陷已经消除。
9. **初始资产估值不完整导致止损基准偏低**：演练中观察到多币持仓重启初期只计算了部分资产，方案基准曾被记录为 1101.11 USDT。现在重连后的 60 秒内拒绝启动方案或切换策略；缺省基准也需等初始化保护期结束再建立。相关回归测试通过，原方案基准已恢复。
